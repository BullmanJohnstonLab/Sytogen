MyMotif

MyMotif allows users to define, import, or edit the restriction-modification (RM) target sequence motifs from a bacterial strain or collection of strains.

RM motifs are the short DNA sequences that restriction endonucleases (REase) recognize as foreign when they are inappropriately methylated or unmethylated; they therefore determine the exact positions in a genetic construct that can be altered during RM-silencing to improve transformation efficiency.

Create a Composite MyMotif file

Upload and edit the motif you want SyToGen to silence. The data can come from recognized motif found through sequencing, from a curated list of motifs you have compiled, or known restriction enzyme target sites. The goal is to create a single composite motif file that contains all the motifs to silence in your construct of interest.

Any uploaded file should contain rows of annotated motifs, with columns for the recognition sequence, methylated base position, and methylation type. This file should be generated by REBASE from PacBio methylome data or MIJAMP motif tables generated from Oxford Nanopore methylome data.

Several files or CSV/TSV motif tables can be uploaded; each one will be appended to the table below.

Any .csv-formatted table is also supported as long as the simple motif is listed with columns annotated as Motif, Recognition sequence, or Sequence are accepted, and methylation fields such as Methylated base and Methylation type are imported when present.

REBASE-tagged records whose enzyme name begins with "M." (e.g. M.Aod1ORFAP) are a standalone methyltransferase, not a restriction enzyme — the site gets methylated but there's no paired enzyme to cut it if it isn't, so these are excluded automatically and won't appear below. This doesn't drop a real RM motif: if the system has an actual restriction enzyme, REBASE represents it as its own record with its own recognition sequence, which is imported normally.

Manually add motif

Manually add the raw motif or known restriction enzyme target sites. Use the dropdown in the recognition sequence field to select from common motifs, or type in your own motif. The methylated base and methylation type will be automatically filled in for known motifs, but can be manually adjusted if needed. For motifs that are not self-reverse-complementary, the complementary strand methylation fields will be disabled and input fields provided below.

This is also how to add a commercial/cloning enzyme site (e.g. BsaI, NotI, EcoRI) that has nothing to do with any host's native RM system. Common reasons: removing incidental internal sites for a Golden Gate/MoClo Type IIS enzyme so only the intended assembly junctions are cut ("domestication"); keeping a unique cutter genuinely unique (e.g. a single NotI site in an MCS, so a linearizing digest gives one clean cut instead of several); protecting your insert from a planned downstream digestion step elsewhere in the construct; or getting a clean, predictable diagnostic-digest banding pattern. SyToGen silences these the same way it silences RM motifs — it just doesn't need any methylome or genome data to do it.

About MyMotif

MyMotif provides a standardized way to create or refine the RM motif set for a bacterial strain, whether or not full PacBio/Oxford Nanopore methylome data are available. SyToGen depends on having an accurate and complete list of RM motifs in a bacterium of interest, which can vary between species, between strains, and even within clonal lineages due to differences in RM system composition (including phase-variable RM systems). Without reliable motif information for a strain or collection of strains, RM-silencing cannot be performed effectively, thus it critical to know which RM motifs need to be addressed to improve transformation efficiency.

MyMotif therefore allows users to inspect, adjust, or supplement their SyToGen compatible motif list; whether to correct incomplete annotations, incorporate new experimentally derived motifs, merge motif collections from multiple strains of interest, or resolve ambiguities introduced by strain-to-strain variation (for example degenerate sequences or motif miscalls).

Additionally, in some cases certain motifs may not require sequence-based RM-silencing because alternative approaches are available. Certain specific motifs can be readily masked by in vitro methylation using matching commercially available methyltransferases or by passage through surrogate strains that introduce the appropriate methylation required to protect against RM activity (for instance, RM systems that recognize Gm6ATC modification can be readily bypassed using common Dam methylase E. coli strains). MyMotif will thus highlight to users when these alternative approaches are available and may be feasible, while still providing the accurate motif list required for downstream steps in the SyToGen workflow.

What does MyMotif do?

MyMotif collects and prepares the RM motif information required for downstream steps in the SyToGen workflow. It imports motif sets from PacBio methylome files, REBASE annotations, MIJAMP-style motif tables, or manual user-provided lists, and allows users to curate or refine these motifs as needed. The module validates motif structure, resolves formatting inconsistencies, and standardizes the motif table so that it can be used reliably by MotifFinder and the core SyToGen module.
